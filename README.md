## Overview
ImageCompressorPro is a lightweight web‑based image compression tool. 
Upload an image (JPEG/PNG) from the browser, the backend compresses it using Pillow, and a download link is returned instantly.

## Features
- Drag‑and‑drop or file‑picker upload
- Real‑time preview
- Adjustable compression quality (default 70%)
- Server‑side validation & size limits (max 5 MiB)
- Detailed logging & error handling
- Unit tests for core compression logic
